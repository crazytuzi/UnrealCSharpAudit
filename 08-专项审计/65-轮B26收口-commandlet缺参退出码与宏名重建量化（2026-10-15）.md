### 2.3 🔴 对裁定材料 `08-…/64` §2.4 的两处实测更正

1. **正控的退出码不是 0，而是 1** —— §2.4 ⑤ 写的是"② `… -Platform=Windows` ⇒ **两态均 exit 0**（不引入回归）"。实测：**两态均为 `1`**。成因（可从读数直接看出，无需读引擎源码）：`-run=` 路径下进程退出码由**引擎的 commandlet 运行器**按 `GWarn` 的 **error 计数**决定——本机该会话**既有 706 error**（`Content/UnitTest/Dynamic/**` 的 4 个 BP 资产，历史基线；成因 = 该会话跳过 `FDynamicGenerator::Generator()`），故打印 `Failure` 并返回非 0；而 `Main` 自己的返回值只在这条之外起作用。
2. ⇒ **`F-ED2-021` 的真实语义分裂**应表述为：**缺参数 = 恒绿**（`Success - 0 error(s)` ＋ 退出码 0，**CI 完全看不见**）／**有参数 = 恒红**（既有 706 error ⇒ 退出码 1，**与生成是否成功无关**）。这正好是 [`08-…/64`](64-裁定材料-F-INT1-004与口径四项（2026-10-15）.md) §3.3 **Q3（先把"什么算失败"固化）** 的实测依据：**在没有固化失败判据之前，退出码只可用于"参数缺失"这一条判据**（本轮的修法正是只取这一条），**不可用于判断"生成是否成功"**。
3. 🆕 **引擎运行器的三态语义（本轮由提交树读数补齐，可直接当台账口径用）**：

| `Main` 返回值 | `GWarn` 的 error 计数 | stdout 行 | 进程退出码 |
|---|---|---|---|
| `0` | `0` | `Success - 0 error(s), N warning(s)` | **0** |
| `0` | `>0` | `Failure - N error(s), M warning(s)` | **1**（按 error 计数） |
| **`非 0`**（本例 `1`） | 任意 | **`Commandlet->Main return this error code: 1`** ＋ `With 0 error(s), N warning(s)`（**不再打印 `Success`/`Failure` 行**） | **1** |

### 2.4 明确不做（保持与原判一致，登记触发条件）

## 7. 复用价值（给下一轮）

1. **"宏调用点数量" ≠ "热点函数调用次数"**：`BINDING_FUNCTION(` 647 处被原文当成"数万次 `FString` 构造"的依据，但那些宏**根本不调用** `TName::Get()`（展开的是函数指针与 `Info` lambda）。**要量化热路径，必须把计数器插在函数体里、按时间线读**，而不是数宏调用点。
2. **退出码不是"有没有报错"，而是"引擎运行器怎么数 `GWarn`"**：`-run=` 会话的进程退出码由**引擎**按 error 计数决定（`Failure - 706 error(s)` ⇒ 1），与 `Main` 的返回值**并存**；三态（`Main`=0/error=0 ⇒ `Success` ＋ 0；`Main`=0/error>0 ⇒ `Failure` ＋ 1；**`Main`≠0 ⇒ `Commandlet->Main return this error code: N`** ＋ `With N error(s)` ＋ N）见 §2.3-3。⇒ 任何"用退出码当 CI 判据"的设计，都要先用**两条真实命令行**取改前读数（本轮若不做这一步，就会沿用裁定材料里"两态均 exit 0"的错误预测）。
3. **"静默失败"的最强证据是"耗时 0.00 秒 ＋ Success"**：缺参数那条分支的 stdout 同时给了三件事——`Success - 0 error(s)`（对外报成功）、`Execution of commandlet took: 0.00 seconds`（其实什么都没干）、退出码 0（CI 无从察觉）。三者叠加才是"CI 无法感知失败"的完整形态。
4. **降级也可以是一条结论**：一条 P2 条目在本轮**零代码改动**下被"事实保留 ＋ 定级下调 ＋ 触发条件登记"处置（同 `F-RM-013`、`F-PERF-024`、`F-CONC-008`、`F-INT1-004` 的库内先例）——**"先量化"的产出就是"可以不修"的**，且必须写清量化口径（次数、单次成本、会话总量）与覆盖边界。
5. **探针的"自我开销"要单列**：`atomic` relaxed 增量实测 **4.3 ns/次**，在被测函数本身只有 47 ns 时占 ~9% ⇒ 报数时要么扣除、要么明示为**上界**（本轮取后者）。
