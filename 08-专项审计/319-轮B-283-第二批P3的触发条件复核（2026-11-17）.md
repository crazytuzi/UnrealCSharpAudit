⇒ 仍是"一次生成 2–3 次"的批量事件；B-210 的 1.85 ms/171 items 结论不受影响。

### 1.2 `F-CS1-022`（`GetMethod` 只按名+参数个数）

- `FPropertyReflection::SetValue`（`:41-45`）→ `ScriptDomain->SetPropertyValue(...)`；**该 SetValue 在插件内没有任何调用方**（全仓 grep 只有定义与声明）；
- `FScriptDomainImpl.inl:426-450` 的实现未变：`GetMethod(Class, PROPERTY_SET_PREFIX + Name, 1)`；
- ⇒ ① 无使用、② 无新增调用方、③ 无编辑器路径 ⇒ 正确性半边仍不可达。

### 1.3 `F-CS2A-008`（`TMap` 慢路径）

- 快路径：`:45 var Buffer = new byte[EnumeratorChunkSize * PairSize]` → `GetPairs(...)` → `Unsafe.ReadUnaligned`（仅双值类型生效）；
- 慢路径：`:71 for (var Index = 0; Index < GetMaxIndex(Handle); Index++)` ＋ 每槽 `GetEnumeratorKey/Value`（非 blittable 键）；
- 该文件自 2026-11-01 无改动；B-152 的"修法无收益/需协议改造"结论仍成立。

### 1.4 `F-CS2B-013`（`FName.NAME_None` 无缓存）

- `FName.cs:61`：`public static FName NAME_None => FNameImplementation.FName_NAME_NoneImplementation();`（每次调用）；
- 消费者仍只有 `Unreal.cs:23/33` 的 null-fallback；`Unreal.cs`/`Object.cs` 自 2026-11-04 无改动；脚本侧 `NewObject<` 仅 1 处；
- ⇒ 触发条件（热循环/泄漏）无证据。

### 1.5 `F-LIFE-008`（UObject 保活 opt-in）

- C# 侧 `Object.AddReference/RemoveReference`（`Object.cs:52-56`）是**公开 API**；C++ 侧 `FRegisterObject.cpp:126-161` 只做绑定注册；
