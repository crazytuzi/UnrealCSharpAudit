## 2. 施工（`+176/−48`）

### 2.1 初始期望 = `Description`，删掉 `EExpect::None`（`:388`）

```cpp
	EExpect Expect = EExpect::Description;
```

`None` 枚举值与 `case EExpect::None` 整块删除（无死分支、无新注释）。首个标签之前的文本从此走 `Description` 分支（`EatWhile(非换行)` ＋ `Save`），成为默认 tag 的描述。

### 2.2 `/` 只剥标记，余量按 `Description`；`*` 成对吃掉 `*/`（`:271-302`、`:304-313`）

```cpp
	case '/':
		{
			OutTextReader.Bump();

			if (current == '/' || current == '*' || current == '!')   // `///` `/**` `/*!` `//!`
			{
				while (...) { OutTextReader.Bump(); }
				return ETokenKind::Trivial;
			}

			if (current == INDEX_NONE || current == '\n' || current == '\r')
			{
				return ETokenKind::Trivial;
			}

			OutTextReader.EatWhile(非换行);
			return ETokenKind::Description;                            // 行首 `/Game/Path` 不再丢
		}
```

`'*'` 分支同时吃掉紧随的 `'/'`（`*/` 成对），避免收尾标记落进文本。

### 2.3 末尾 `*/` 裁剪（`:426-441`）

```cpp
	auto TextLen = InText.Len();

	while (TextLen > 0 && (末字符为 \n/\r/空格/\t)) { --TextLen; }

	if (TextLen >= 2 && InText[TextLen - 2] == '*' && InText[TextLen - 1] == '/') { TextLen -= 2; }

	auto Text = InText.SubStr(0, TextLen);
```

**动机**：单行注释 `/** Just a plain comment. */` 的 `*/` 位于行中，`Description` 的 `EatWhile`（只到换行）会把它一起吃进 summary。裁剪在**最外层**做一次，`Tokenize`/`Slice` 全部改用 `Text`；多行注释的 `*/` 本来由 `'*'` 分支剥掉，行为不变。

## 4. 边界与残余

1. **有 `@brief` 时，`@brief` 之前的自由文本仍不输出**：默认 tag 只在 `BriefIndex == INDEX_NONE` 时当 summary（`:555`）。Doxygen 语义里这段属 details，本轮未做 details 落位；若日后要做，落点是 `<remarks>`。
2. **未知标签只降到"纯文本行"**：`note:`/`see:`/`warning:` 前缀保留了标签词，但没有做 `<remarks>` / `<seealso cref="…"/>` 之类的标准标签映射 —— `cref` 一旦解析不到会引入 **CS1574**，与"0 warning"闸门冲突，故不做。
3. **`<code>` 内容不是 CDATA**：`<`/`>` 在调用点已转义为 `&lt;`/`&gt;`，IDE 里显示为实体原文（与改前的编码路径一致，非本轮退化）。
4. **裸 `\` 仍被当标签起始**：`C:\Game` 会产出 `Game: …` 文本行（改前是 `<Game>` 假标签）。属词法面遗留，未在本轮扩大范围。
5. **行尾空格**：`/** Foo */` 的输出是 `/// Foo `（源文本末尾的空格保留）。生成物不是交付面、未做 `TrimEnd`；若将来要过 `diff --check` 式检查需在 emitter 里补。
6. **只测 UE 5.6 / Windows**：本轮无新增引擎 API，跨版本依据 = §7 `b29 -Mode Syntax` CLEAN ＋ 所用手法（`FStringView::Len/SubStr/operator[]`、`TStringBuilder::Append`）全部是**改动前已在同文件使用**的面。
