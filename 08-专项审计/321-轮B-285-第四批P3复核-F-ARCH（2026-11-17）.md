## 1. 逐条依据

### 1.1 `F-ARCH-001`（Runtime → Editor 反向依赖）

```csharp
// Source/UnrealCSharp/UnrealCSharp.Build.cs:50-55（HEAD）
if (Target.bBuildEditor)
{
	// …
	"UnrealEd",
```

- 依赖被 `bBuildEditor` 限制在编辑器目标内 ⇒ 打包运行时不受影响，但**分层仍被破坏**（Runtime 模块的编辑器目标编译期依赖引擎 Editor 模块）；
- 文件自 2026-10-08 复核基线起无改动 ⇒ 前提成立、级别不变。

### 1.2 `F-ARCH-002`（`WITH_LEANCLR` 进入生成产物）

| 位置 | 形态 |
|---|---|
| `Script/SourceGenerator/UnrealTypeSourceGenerator.cs:1258/1298` | 生成器模板字符串里直接拼 `"#if WITH_LEANCLR\n"` |
| `Script/UE/CoreUObject/Utils.cs:15/232` | 生成产物内 `#if WITH_LEANCLR` / `#if !WITH_LEANCLR` |

⇒ 后端差异仍会出现在**用户工程的生成代码**中；总命中 10 处。

### 1.3 `F-ARCH-003`（两条生成路径）

- UHT 导出器：`Source/SourceCodeGenerator/SourceCodeGenerator.cs`（子模块）仍在；
- 编辑器运行时生成器：`FAssetGenerator`/`FBindingClassGenerator`/`FBindingEnumGenerator`/`FClassGenerator`/`FDelegateGenerator`/`FEnumGenerator` 等仍在；
- ⇒ "两条路径"事实成立；报告里"输出目录是否重叠"仍标为未验证（不在本轮范围）。

### 1.4 `F-ARCH-004`（后端不对称）
