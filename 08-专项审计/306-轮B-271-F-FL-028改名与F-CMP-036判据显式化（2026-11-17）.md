### 1.2 `F-CMP-036`：判据显式化 ＋ Linux 安装根

```cpp
// FUnrealCSharpFunctionLibrary.cpp:1845-1857
bool FUnrealCSharpFunctionLibrary::IsDotNetSdkSupported(const FString& InDotNetPath)
{
	int32 MajorVersion = 0;

	int32 MinorVersion = 0;

	if (!GetDotNetSdkVersion(InDotNetPath, MajorVersion, MinorVersion))
	{
		return false;
	}

	return MajorVersion >= GetDotnetVersion();
}
```

```cpp
// FUnrealCSharpFunctionLibrary.cpp:1941-1946
#else
	SearchPaths.Add(TEXT("/usr/share/dotnet"));

	SearchPaths.Add(TEXT("/usr/lib/dotnet"));

	SearchPaths.Add(TEXT("/usr/lib64/dotnet"));
#endif
```

- **为什么删 minor**：`MinorVersion` 是 SDK 目录名（`10.0.403`）的第二段，恒 `0`；`DOTNET_MINOR_VERSION` 三域硬编码 `0` ⇒ 旧 `MinorVersion >= DOTNET_MINOR_VERSION` **恒真**（死条件），且 TFM minor 一旦非 0 会把所有候选判成"不支持"。删除后谓词只剩一条比较，语义与命名一致。
- **为什么补 Linux 根**：`GetDotNetSdkVersion` 用 `FPaths::GetPath(exe)` 当安装根；deb/rpm 的 `/usr/bin/dotnet` 是符号链接 ⇒ 其同级无 `sdk/` ⇒ 该候选恒 `false`。补的两个根是 deb（`/usr/lib/dotnet`）与 rpm（`/usr/lib64/dotnet`）的**真实安装位置**，使"判据恒假"在主流布局下可恢复为真。
- **未做的**：读 `global.json` / 比 patch 与 feature band / shim 型 exe 的假阴性 —— 属**设计面**（需新契约与新门控），登记为残余与触发条件（§3.2）。

### 3.3 `F-BIND-013` 类型名位置普查（本轮非代码产出）

**结论：空类型名在"类型位"上的插值点 = 11 处，全部未守；它们与本轮无关（同属 5.8 专属面）。**

| # | 位置（`FBindingClassGenerator.cpp`） | 用途 | 空名后果 |

### 3.4 `F-CB-022` 无锁契约（本轮非代码产出）

契约页：[`08-…/307`](307-契约页-Children链线程亲和与RemoveFunction归属（2026-11-17）.md) —— 两条契约：

- **C-CHILDREN-1**：`Class->Children` 链只在**游戏线程**读写；`FCSharpBind::RemoveFunctionFromClass` 必须在游戏线程调用；禁止在 GC/序列化/编辑器 UI 线程并发（`FuncMap` 有 `FUClassFuncScopeWriteLock`，`Children` **没有**任何锁）。
- **C-REMOVE-1**：`UClass.RemoveFunction(FName)` 只删**本类自有**函数；继承函数 = **静默 no-op**（`ExcludeSuper`），不得用它做"跨类删除"。

⇒ `F-CB-022` 行由"部分修"补挂契约页链接与触发条件（级别仍 P3）。
