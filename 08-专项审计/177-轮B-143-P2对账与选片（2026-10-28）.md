## 3. 选片预读（3 条）

### 3.1 `F-PERF-022`（S=2.44 · 活跃）⇒ 🟢 **立项**

**HEAD 事实**（`Source/Compiler/Private/FCSharpCompileProgress.cpp:39-55`）：

```cpp
void FCSharpCompileProgress::SetOutput(const FString& InOutput)
{
    FScopeLock ScopeLock(&CriticalSection);
    PendingOutput.Append(InOutput);
    int32 Index = INDEX_NONE;
    while (PendingOutput.FindChar(TEXT('\n'), Index))   // 每行从头扫
    {
        auto Line = PendingOutput.Left(Index);          // 每行拷一次
        PendingOutput.MidInline(Index + 1);             // 每行把剩余缓冲整体前移 ⇒ O(L·B)
        ProcessLine(Line);
    }
}
```

**为什么是 P2 而非噪声**：`PendingOutput` 是**整段 MSBuild 输出**（`FCSharpCompilerRunnable` 一次喂入），行数 L 与总字节 B 同量级 ⇒ 每行 `MidInline` 搬 B 字节 ⇒ **O(L·B)**；一次编译会话里 `SetOutput` 被调用多次（每个 chunk 一次），放大面随输出增长。

**修法（≈12 行、1 文件）**：改**游标式**扫描 —— `FindChar('\n', Index, Start)` 只前进不回退；每行 `Mid(Start, Index-Start)`；循环结束后 `PendingOutput.RightChopInline(Start)` 一次性裁掉已处理前缀（`Start == 0` 时不裁）。语义等价（`ProcessLine` 的输入逐行相同；未完成行继续留在缓冲区）。

**判据（B-144 施工时取）**：
1. **微基准**：同一二进制内喂 5 000 行 × 200 字符，A/B 计时（临时探针，编辑器会话；沿用 B-40 的口径），预期 O(L·B) → O(B)；
2. 套件 **1 987/0 同 SHA `D520F5AD…`**（本改动不触运行期语义）；
3. 产物 manifest 0 差异；§7/§8 PASS。
