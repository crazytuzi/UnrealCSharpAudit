## 3. 修法（快照原子发布）

### 3.1 代码事实（改后，`Script/Interop/Bridge/MethodBridge.cs`）

```csharp
// :14-21 两张字典收进一个不可变快照，字段用 volatile 发布
private static volatile MethodBindings Bindings = new();

private sealed class MethodBindings
{
    public readonly Dictionary<string, nint> Methods = new(StringComparer.Ordinal);

    public readonly Dictionary<string, int> ParamCounts = new(StringComparer.Ordinal);
}
```

```csharp
// :26-50 RegisterBinding：先在本地表填满，再一次性发布
var PendingBindings = new MethodBindings();
...
    PendingBindings.Methods[Name] = InMethods[Index];
    PendingBindings.ParamCounts[Name] = InParamCounts[Index];
...
if (PendingBindings.Methods.Count > 0)
{
    Bindings = PendingBindings;

```

```csharp
// :160-174 GetMethod：只读一次引用，两张表来自同一快照
if (InSlot == nint.Zero)
{
    var BindingsSnapshot = Bindings;

    InSlot = BindingsSnapshot.Methods.TryGetValue(InName, out var Method) &&
             BindingsSnapshot.ParamCounts.TryGetValue(InName, out var ParamCount) &&
             (ParamCount == UnknownParamCount || ParamCount == InParamCount)
        ? Method
        : nint.Zero;
}
```

```csharp
// :221-224 Clear：换空快照，不再原地 Clear 两张可变字典
internal static void Clear()
{
    Bindings = new MethodBindings();
}
```

> **命名依据**（沿用仓内先例）：类名 `MethodBindings` = 方法绑定集（`MethodBindings` 全仓 0 撞名；不叫 Table —— 仓内 C# 侧同类结构是 `HandleData`／`HandleReference`，无 `XxxTable` 先例）；`PendingBindings` = 待发布的那一版（先例 `PendingBindClasses`／`PendingBindObjects`／`PendingBytes`）；`BindingsSnapshot` = `Bindings` 的一次性只读快照（先例 `FileChangesSnapshot = MoveTemp(FileChanges)`，锁内拷、锁外读）。`Current*` 在本仓是**迭代游标**（`CurrentIndex`／`CurrentField`／`CurrentClass`），不代表"已发布版本"，故不采用。

### 3.2 契约

1. **`RegisterBinding` = 全量发布（replace）**：唯一 native 调用点 `FScriptDomainImpl.inl:610-659` 每次把 `FBinding` 全量枚举成数组（实测 1 998 条）⇒ replace 与原 merge 语义**等价**；空输入（`PendingBindings.Methods.Count == 0`）**不发布**，与改前"什么都不写"一致。
2. **已发布的快照不可变**：`GetMethod` 拿到的引用在整个调用期间不会被原地修改 ⇒ 消除了 `Dictionary` 并发读写的 UB，也消除了"方法/参数个数分别写入"的跨表撕裂。
3. **代价**：`RegisterBinding` 多分配一次快照（1 998 条、域初始化一次）；`GetMethod` 多一次 `volatile` 读（仅首命中路径），**槽命中路径零改动**。
4. **无新公开面**：`MethodBindings` 是 `private sealed` 嵌套类型；`RegisterBinding`/`GetMethod`/`Clear` 签名不变。
