## 4. C1 的语义（伪代码）

```cpp
// 1) FUnrealCSharpModuleDelegates：加"已激活"状态 ＋ 回放式订阅
static bool bIsModuleActive = false;                 // 由 Broadcast 方置真
TDelegateHandle AddRawWithReplay(UserClass*, void (UserClass::*Fn)());

// 2) FUnrealCSharpModule::OnUnrealCSharpCoreModuleActive()
FUnrealCSharpModuleDelegates::SetModuleActive(true); // 先置真
FUnrealCSharpModuleDelegates::OnUnrealCSharpModuleActive.Broadcast();

// 3) FCSharpEnvironment 的 ctor：改用回放式订阅
OnActiveHandle = FUnrealCSharpModuleDelegates::AddRawWithReplay(this, &FCSharpEnvironment::OnUnrealCSharpModuleActive);
```

**回放去重**：`AddRawWithReplay` 在"已激活"时**同步调用一次** handler；而 `OnUnrealCSharpModuleActive` 自身幂等（`IsInitialized()` 守卫在 `FScriptDomainImpl`/`FDomain` 一侧已存在）⇒ 不需要额外去重。

**与解耦的关系**：置真/回放都在 `FUnrealCSharpModuleDelegates`（`UnrealCSharp` 模块自己的公开头）里；`UnrealCSharp.cpp` 只多一行 `SetModuleActive(true)`，**不引用环境**。环境侧只改 ctor 的订阅方式。✅ 满足约束 1。
