## 2. 施工

### 2.1 形态切换（如实登记）

按维护者决定先实现 **A（`__COUNTER__` 作 `TFunctionInfo` 类型参数）**，编译失败：

```
Public/Binding/Class/TBindingClassBuilder.inl(18,52): error C3878: syntax error: unexpected token ')' following 'jump-statement'
Public/Binding/Class/TClassBuilder.inl(139,2): ...
```

原因：绑定宏在**模板上下文**里使用（`TClassBuilder<T, IsProjectClass0>::Constructor(BINDING_CONSTRUCTOR(T))`、`TClassBuilder<T>::BINARY_OPERATOR(...)`）⇒ `Builder::Info<__COUNTER__>(...)` 的 `Info` 是**依赖名**，`<` 被当成小于号。加 `::template` 可过 MSVC，但对 Clang（Mac/iOS/Android/Linux）在非依赖上下文里的 `template` 关键字属实现宽容度问题，不可在本机取证。

⇒ 改为 **A′：把元数据对象本身放到宏展开的 lambda 里**（每展开一个闭包类型 ⇒ 一个 static），不引入任何模板实参：

```cpp
// BindingMacro.h（5 个 *_BUILDER_INFO 统一形态）
#define BINDING_FUNCTION_BUILDER_INFO(Function, ...) \
	{ \
		[]() -> FFunctionInfo* \
		{ \
			static auto Instance = TFunctionBuilder<decltype(Function), Function>::Make(__VA_ARGS__); \
			return &Instance; \
		} \
	}

// TFunctionInfoBuilder.inl：Info() → 4 个 Make()（按值返回，与 4 个 Get 形态一一对应）
static auto Make();                                                     // 默认构造
template <typename... D> static auto Make(const TArray<FString>&, D&&...); // 名字 + 默认值
static auto Make(const EFunctionInteract);                               // 交互标志
template <typename... D> static auto Make(const TArray<FString>&, const EFunctionInteract, D&&...);
```

- `TFunctionInfo.inl` **回到原样**（tag 参数已回退），`TFunctionInfo` 的四个 `Get` 重载不动（现无调用者，保留为兼容形态）。
- 身份来源从"thunk 地址"变成"**闭包类型**"：同 TU 每次展开唯一；**跨 TU 也唯一**（闭包类型内部链接）——比 tag 更强。
- 初始化仍是**首次调用时惰性构造**（`static` 在 lambda 体内），生命周期到进程退出。
- 构造/析构/下标三个宏同步改成 `Make()` 形态（它们本来就无元数据差异，行为不变）。
