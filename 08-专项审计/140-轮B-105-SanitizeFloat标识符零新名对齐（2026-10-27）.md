## 2. 终态（`TDefaultArgument.inl:5-79`）

```cpp
inline FString SanitizeFloat(double InFloat, const int32 InMinFractionalDigits = 1)
{
	InFloat = InFloat == 0.0 ? 0.0 : InFloat;

	FString TempString;

	if (InFloat != 0.0 && FMath::IsNearlyZero(InFloat, 0.5e-6))
	{
		TempString = FString::Printf(TEXT("%.9f"), InFloat);
	}
	else
	{
		TempString = FString::Printf(TEXT("%f"), InFloat);
	}

	int32 TrimIndex = INDEX_NONE;

	int32 DecimalSeparatorIndex = INDEX_NONE;

	for (auto CharIndex = TempString.Len() - 1; CharIndex >= 0; --CharIndex)
	{
		const auto Char = TempString[CharIndex];

		if (Char == TEXT('.'))
		{
			DecimalSeparatorIndex = CharIndex;

			TrimIndex = FMath::Max(TrimIndex, DecimalSeparatorIndex);

			break;
		}

		if (TrimIndex == INDEX_NONE && Char != TEXT('0'))
		{
			TrimIndex = CharIndex + 1;
		}
	}

	TempString.RemoveAt(TrimIndex, TempString.Len() - TrimIndex,
#if UE_F_STRING_REMOVE_AT_E_ALLOW_SHRINKING
	                    EAllowShrinking::No
#else
	                    false
#endif
	);

	if (InMinFractionalDigits > 0)
	{
		if (TrimIndex == DecimalSeparatorIndex)
		{
			TempString.AppendChar(TEXT('.'));
		}

		const auto NumFractionalDigits = (TempString.Len() - DecimalSeparatorIndex) - 1;

		if (const auto FractionalDigitsToPad = InMinFractionalDigits - NumFractionalDigits;
			FractionalDigitsToPad > 0)
		{
			TempString.Reserve(TempString.Len() + FractionalDigitsToPad);

			for (auto Cx = 0; Cx < FractionalDigitsToPad; ++Cx)
			{
				TempString.AppendChar(TEXT('0'));
			}
		}
	}

	if (InFloat != 0.0 && FMath::IsNearlyZero(InFloat, 0.5e-9))
	{
		TempString = FString::Printf(TEXT("%.9g"), InFloat);
	}

	return TempString;
}
```

## 4. 与引擎"仍存的差异"（**无命名差异**）

| 类别 | 内容 | 保留理由 |
|---|---|---|
| 精度档位 | 引擎 `%f`（6 位）＋ 我们两个**无名回退分支**（`≤0.5e-6 → %.9f`、`≤0.5e-9 → %.9g`） | 引擎会丢 `1e-8` 类默认值（B-104 §2） |
| 负零 | 引擎调 `UE::Core::Private::StripNegativeZero`（`+= 0.0f`） | 该符号 5.0 只在 `String.cpp` 内、5.4 才公开（B-104 §1） |
| 非数值早退 | 引擎 `if (!TempString.IsNumeric()) return TempString;` | 对 `inf`/`nan` 输出无差异；加早退会多一个出口 |
| 断言 | 引擎 `check(TrimIndex != INDEX_NONE && DecimalSeparatorIndex != INDEX_NONE);` | G7 禁新增断言 |
| `RemoveAt` | 引擎 `EAllowShrinking::No`；本仓 `#if` 门控 | 5.0–5.3 只有 `bool` 重载（B-104 §3） |
| 字符类型 | 引擎 `UE_STRING_CLASS`/`ElementType`/`CHARTEXT` 模板族 | 本仓只需 `FString`（TCHAR） |
