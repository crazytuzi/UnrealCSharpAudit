# 轮 B-141：`F-PROP2-012 (05)` 复核 —— UHT 禁止 sparse 委托作函数参数（归档）（2026-10-28）

> **来源**：B-139 立项 ②（[`08-…/173`](173-轮B-139-T3第九次选片与台账收尾（2026-10-28）.md) §3）。
> **结论**：**不修，归档为「不可达」** —— 静态缺陷形态（`FMulticastDelegatePropertyDescriptor` 无 `FParameter` 覆写）成立，但其"活跃"前提**被 UHT 实测否证**：`FMulticastSparseDelegateProperty` 的委托类型（`TSparseDynamicDelegate` 派生结构）**不能作为 UFUNCTION 参数**，UHT 直接报错；而 inline 多播委托参数走 `GetMulticastDelegate` 时地址本身就是按值缓冲的 `FMulticastScriptDelegate` ⇒ 本来就正确。

## 1. 静态形态（缺陷形态成立）

- `FPropertyDescriptor::Get(void* Src, void** Dest, FPropertyArgument::FParameter)`（`FPropertyDescriptor.cpp:144-147`）直接转发 `FMember`；
- `FMulticastDelegatePropertyDescriptor.h:11-17` **没有** `FParameter` 覆写；
- `GetMulticastDelegate` 走 `Property->GetMulticastDelegate(InAddress)`；sparse 侧的 `FMulticastSparseDelegateProperty::GetMulticastDelegate`（`PropertyMulticastDelegate.cpp`）把地址当 **成员地址**：
  ```cpp
  const FSparseDelegate* SparseDelegate = (const FSparseDelegate*)PropertyValue;
  USparseDelegateFunction* SparseDelegateFunc = CastChecked<USparseDelegateFunction>(SignatureFunction);
  UObject* OwningObject = FSparseDelegateStorage::ResolveSparseOwner(*SparseDelegate, SparseDelegateFunc->OwningClassName, SparseDelegateFunc->DelegateName);
  ```
  且 `ResolveSparseOwner`（`SparseDelegate.cpp`）按 `(OwningClassName, DelegateName)` 查偏移后 `address - offset` 反推 owner，查不到即 `check(false)`。

## 2. 可达性复核（本轮的关键）

**探针**（临时，已删除）：在工程侧加一个 `UCLASS`，含 `DECLARE_DYNAMIC_MULTICAST_SPARSE_DELEGATE_OneParam` 声明 ＋ 一个以该委托类型为参数的 `UFUNCTION`：

```cpp
DECLARE_DYNAMIC_MULTICAST_SPARSE_DELEGATE_OneParam(FOnSparseProbe, UTestSparseDelegateProbe, OnSparseProbeValue, int32, Value);

UPROPERTY(BlueprintAssignable)
FOnSparseProbe OnSparseProbeValue;

UFUNCTION(BlueprintCallable)
void TakeSparseProbe(FOnSparseProbe InSparseProbe) {}
```

**UHT 实测**（`Saved/Retest/b141/probe-ubt.log`）：

```
D:\...\TestSparseDelegateProbe.h(19): Error: Type 'FOnSparseProbe' is not supported by blueprint.
    Function:  TakeSparseProbe Parameter InSparseProbe
Result: Failed (OtherCompilationError)   exit 6
```

⇒ **sparse 委托不可能出现在 UFUNCTION 参数位上**（`FParameter` 路径永远拿不到 `FMulticastSparseDelegateProperty`）。

**其余调用面**也都传真实成员地址：`NewRef`/`NewWeakRef`/`Set`/`Identical` 均来自属性访问（`GetMulticastDelegate(InAddress)` 的 `InAddress` 是属性成员地址）；**inline** 多播委托的参数缓冲本身就是 `FMulticastScriptDelegate` ⇒ `GetMulticastDelegate` 的 `(FMulticastScriptDelegate*)PropertyValue` 转换**正确**。
