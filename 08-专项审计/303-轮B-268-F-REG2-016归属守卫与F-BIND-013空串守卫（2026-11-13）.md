## 1. 改动清单

### 1.1 `F-REG2-016`：`FRegisterClass.cpp:20`

```cpp
					if (const auto Function = FoundClass->FindFunctionByName(*Name, EIncludeSuperFlag::ExcludeSuper))
```

- **为什么这一行就够**：`RemoveFunction` 的语义是"删掉**这个类**上的函数"。把查找限制在本类 `FuncMap`（`ExcludeSuper`）后：
  1. **继承函数不再被删** ⇒ 不会再有"从子类删掉 `AActor::ReceiveBeginPlay`"的全局删除面；
  2. **调用者类的缓存不再被留悬垂** —— B-267 的 P2 实质是"`FindFunctionByName` 把继承结果缓存进**被查询类**，而 `RemoveFunctionFromFunctionMap` 只清**被调用者自己**"。既然继承函数根本不会被选中，这条路径自然消失；自有函数被删时，`RemoveFunctionFromFunctionMap` 会同时清 `FuncMap` 与 `AllFunctionsCache`（5.6 `Class.h:3276-3287`），缓存一致。
- **不选"比较 `Function->GetOuter()`"的理由**：语义等价但多一个分支；`ExcludeSuper` 是引擎既有形参（5.0 `Class.h:2982` / 5.6 `:3293` / 5.8 `:4291` 同签名），且本仓已有同形用法（`FCSharpBind.cpp:424` `FindFunctionByName(FunctionName, EIncludeSuperFlag::ExcludeSuper)`）⇒ **零新增概念**。
- **行为边界**：`RemoveFunction` 的入参是 C# 侧 `FName`；若 C# 用户传入继承函数名，现在是**静默 no-op**（G7 禁日志，无返回值通道）。这与"只删本类函数"的契约一致；契约需写进 `F-REG2-016` 的残余说明（§3.1）。

### 1.2 `F-BIND-013` 之"空命名空间"：3 处同形守卫

| 文件:行（提交 `1a49d72`） | 改动 |
|---|---|
| `FBindingClassGenerator.cpp:735` | `UsingNameSpaces.Remove(TEXT(""));`（`GeneratorPartial`，紧随既有 `Remove(NameSpaceContent[0])`） |
| `FBindingClassGenerator.cpp:1026` | `UsingNameSpaces.Remove(TEXT(""));`（`GeneratorImplementation`，`Sort` 之前） |
| `FAssetGenerator.cpp:168` | `UsingNameSpaces.Remove(TEXT(""));`（`SuperClass` 的命名空间可能为空） |

- **形态依据（§8.1-A⑤ 命名/形态一致）**：仓内已有 **4 处**同一行 —— `FClassGenerator.cpp:813`、`FStructGenerator.cpp:300`、`FDelegateGenerator.cpp:345`、`:671`。⇒ 本轮不是发明修法，而是把**漏掉的两处（实为三处循环）补齐**。
- **为什么必须补**：`TNameSpace<E>::Get()` 在 5.8 兜底失败时返回 `{""}`，`UsingNameSpaces` 是 `TSet<FString>` 且由 `Append(Param->GetNameSpace())` / `Append(Property.GetNameSpace())` 填充（`FBindingClassGenerator.cpp:62-64/174/327/336/868-870/919/998`）⇒ 空串会进集合，循环里就会生成 **`using ;`**（非法 C#）。
- **`FAssetGenerator` 的那一处**：`UsingNameSpaces.Add(GetClassNameSpace(SuperClass))`，而 `GetClassNameSpace(const UStruct*)` 对 `nullptr` 返回 `TEXT("")`（`FUnrealCSharpFunctionLibrary.cpp:453-458`）⇒ 与另两处同根因。

### 1.3 `F-BIND-013` 之"空默认值"：`FBindingClassGenerator.cpp:368-377`

```cpp
					if (Params[Index]->IsPrimitive())
					{
						if (const auto& DefaultArgument = DefaultArguments[DefaultArgumentIndex];
							!DefaultArgument.IsEmpty())
						{
							DefaultParam = TEXT(" = ");

							DefaultParam += DefaultArgument;
						}
					}
```

- **改前**：`DefaultParam = FString::Printf(TEXT(" = %s"), *DefaultArguments[...])` —— primitive 分支**没有** `IsEmpty()` 守卫（同函数的非 primitive 分支 `:379` 反而有），空默认值会生成 **`EFoo X = ,`**。
- **改后**：空 ⇒ `DefaultParam` 保持空（该参数**不带默认值**），非空 ⇒ 结果与原文逐字相同（`" = " + 值` ≡ `Printf(" = %s")`）。
- **形态选择**：① 判空用 **if-init**（`if (const auto& X = …; !X.IsEmpty())`）—— 仓内既有写法（`FUnrealCSharpFunctionLibrary.cpp:1856`、`FClassDescriptor.cpp:26` 同形）；② `Printf` 拆成两次赋值的理由是**避免对齐续行**：原 `Printf` 的实参靠 `TAB+空格` 对齐到字面量列，外层多一层 `if` 后该列要整体右移，拆开后 `SpaceAlgn` 读数保持 0、`AddedMax` 79 < 110。
