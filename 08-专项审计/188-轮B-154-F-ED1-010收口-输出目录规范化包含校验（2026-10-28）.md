## 2. 施工（`+20/−1`）

TU 局部谓词（不新增公开 API、不加日志/注释，G7）：

```cpp
static bool IsClassPathUnderProjectDirectory(const FString& InClassPath, const FString& InProjectSourcePath)
{
    auto FullClassPath = FPaths::ConvertRelativePathToFull(InClassPath);
    auto FullProjectSourcePath = FPaths::ConvertRelativePathToFull(InProjectSourcePath);

    FPaths::CollapseRelativeDirectories(FullClassPath);
    FPaths::CollapseRelativeDirectories(FullProjectSourcePath);

    while (FullProjectSourcePath.EndsWith(TEXT("/")))
    {
        FullProjectSourcePath = FullProjectSourcePath.LeftChop(1);
    }

    return FullClassPath.Equals(FullProjectSourcePath, ESearchCase::IgnoreCase) ||
        FullClassPath.StartsWith(FullProjectSourcePath + TEXT("/"), ESearchCase::IgnoreCase);
}
```

调用点：

```cpp
if (IsClassPathUnderProjectDirectory(NewClassPath, AvailableProject->SourcePath))
```

- 大小写：沿用原 `StartsWith` 的 **IgnoreCase**（Windows 语义不变）；
- 边界：要求 `目录 + '/'`，消除 `Script2` 类误判；相等情形保留（与原 `StartsWith` 允许同一路径一致）。
