## 1. 协议设计

### 1.1 原生侧（`FRegisterArray.cpp`）

```cpp
static int32 GetElementsImplementation(const IManagedHandle InManagedHandle, const int32 InIndex,
                                    const int32 InCount, uint8* OutBuffer, const int32 InBufferSize)
{
    if (const auto ArrayHelper = ...GetContainer<FArrayHelper>(InManagedHandle))
    {
        const auto TypeSize = ArrayHelper->GetTypeSize();

        if (TypeSize > 0 && InIndex >= 0 && InCount > 0 && OutBuffer != nullptr)
        {
            const auto Available = ArrayHelper->Num() - InIndex;
            const auto MaxCount = InCount < Available ? InCount : Available;

            if (MaxCount > 0 && static_cast<int64>(MaxCount) * TypeSize <= InBufferSize)
            {
                for (auto Index = 0; Index < MaxCount; ++Index)
                {
                    FMemory::Memcpy(OutBuffer + static_cast<int64>(Index) * TypeSize,
                                    ArrayHelper->Get(InIndex + Index), TypeSize);
                }

                return MaxCount;
            }
        }
    }

    return 0;
}
```
注册 `.Function("GetElements", GetElementsImplementation)`；C# 的 `LibraryBridgeGenerator` 自动生成 `__TArray_GetElementsImplementation` 桥接（键与既有 `Num/Get` 同形，**无需重生产物**）。

### 1.2 C# 侧（`TArray.cs`）

```csharp
var Handle = HandleData.GetHandle(this);
var ElementSize = Unsafe.SizeOf<T>();

if (typeof(T).IsValueType && TArrayImplementation.TArray_GetTypeSizeImplementation(Handle) == ElementSize)
{
    var Buffer = new byte[EnumeratorChunkSize * ElementSize];   // 256 元素
    var Index = 0;

    while (true)
    {
        var Count = GetElements(Handle, Index, EnumeratorChunkSize, Buffer);

        for (var Offset = 0; Offset < Count; Offset++)
        {
            yield return Unsafe.ReadUnaligned<T>(ref Buffer[Offset * ElementSize]);
        }

        if (Count < EnumeratorChunkSize) { yield break; }

        Index += Count;
    }
}

// 兜底：compound / 布局不一致 ⇒ 原逐元素路径（2 次 P/Invoke/元素）
```

**三个关键决定**：

1. **分块而非全量快照**：全量快照要把 N 个元素一次拷进托管堆（大数组多一次 N×size 分配），分块用固定 256 元素缓冲（1 KB 级），块间重新取长度 ⇒ 更接近原语义。
2. **`GetTypeSize == Unsafe.SizeOf<T>()` 作为布局契约**：不匹配（compound、含引用字段的 struct、bool 以外的特殊布局）直接走兜底，**绝不把错布局的字节读成 T**。
3. **`yield` 不能进 `fixed`**：`fixed` 放在 `GetElements` 辅助方法里，枚举器只读托管数组。

## 5. 复用价值

1. **"批量"要分块，不要一次快照**：固定 256 元素缓冲既把 P/Invoke 降到 1/256，又不引入 N 元素的一次性分配，还能在块间重新取长度。
2. **布局契约用 `GetTypeSize == Unsafe.SizeOf<T>()` 一句话判定**：不匹配就兜底，避免把 compound/特殊布局读坏。
3. **`yield` 与 `fixed` 互斥**：把 `fixed` 收进一个返回 `int` 的辅助方法，枚举器只碰托管数组。
4. **新增 interop 导出的成本很低**：注册一行 ＋ C# 声明一个 partial，桥接由 `LibraryBridgeGenerator` 自动生成，**不需要重生产物**。
