## 2. 第 2 步：`IsInitialized()` 说谎的修正（`+4` 行 ＋ 1 个成员）

**改前语义**：`IsInitialized()` = 「288 链上的成员是否都非空」。`Deinitialize()` 之后成员仍指向**已 delete** 的对象 ⇒ 返回 **true**（谎报已初始化）。

**改法**（3 处）：

| 位置 | 改动 |
|---|---|
| `FReflectionRegistry.h` 私有段 | 新增 `bool bIsInitialized{};` |
| `Initialize()` 末尾 | `bIsInitialized = true;` |
| `Deinitialize()` 首行 | `bIsInitialized = false;`（先降旗再删对象） |
| `IsInitialized()` | `return bIsInitialized && <原 288 项判空链>;` —— 短路求值 ⇒ **反初始化后不再触碰悬垂成员** |

**语义等价性逐态核对**：

| 状态 | 改前 | 改后 |
|---|---|---|
| 从未 `Initialize()` | false（成员全空） | false（标志 false 短路） |
| `Initialize()` 成功 | true | true（标志 true ＋ 链全非空） |
| `Initialize()` 部分失败（某 C# 类缺失） | false（链上有空） | false（标志 true，链短路到空项） |
| **`Deinitialize()` 之后** | **true（谎报，且读到悬垂指针）** | **false（正确，且不读悬垂）** |
