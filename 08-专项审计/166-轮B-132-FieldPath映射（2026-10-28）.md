## 3. 边界

1. **只测 `TFieldPath<FField>`**：这是当前 C# 侧**唯一存在**的 FieldPath 泛型实参（`Script/UE/CoreUObject/TFieldPath.cs:8` 的约束 `where T : FField`，且 `Script/Reflection/Property` 下只有 `FField` 一个字段类标记）。C++ 用 `TFieldPath<FIntProperty>` 之类时生成器会产出 `TFieldPath<FIntProperty>`，而**该 C# 类不存在**（全库 0 命中）——这是**既有**生成器缺口，与本轮映射无关，**未取号**（建议下一轮查重后归档）。
2. **只验"属性物化 ＋ 类型正确"**：未断言 C# 侧对该属性的 get/set 语义（既有 `FieldPathPropertyWriteRead` 等 4 条判据两态皆 true，只能说明未被破坏）。
3. **`[UFunction]` 形参/返回值半边未测**（同一 `GetPropertyType` 修复会让 FieldPath 形参也物化）。
4. **泛型实参 → 字段类**走 `GetName().RightChop(1)` ＋ `GetNameToFieldClassMap()`：即"C# 名去首字母 F"的命名契约；若将来出现不在该 map 里的字段类（自定义 `FField` 子类），会返回 `nullptr`（属性丢弃，不崩）。
5. **5.4 / 5.8 实编未取得**（§2.6）。
6. 工程侧语料含预存 WIP（§1.2 警示）⇒ 提交需按 hunk 拣选。
