## 2. `F-CS2A-025` —— `new TOptional<T>(null)` / `Set(null)` 在进入 native 前抛异常

### 2.1 事实与语义裁定

**改动前**（`TOptionalImplementation.cs`，`5593df88` 的父）：

```csharp
// Script/UE/Library/TOptionalImplementation.cs:19-23（改前）
public static unsafe void TOptional_Register2Implementation<T>(TOptional<T> InOptional, T InValue, Type InType)
{
    __TOptional_Register2Implementation(HandleData.Alloc(InOptional, true),
        HandleData.Alloc(InValue), HandleData.Alloc(InType));
}

// :76-79（改前）
public static unsafe void TOptional_SetImplementation<T>(nint InOptional, T InValue)
{
    __TOptional_SetImplementation(InOptional, HandleData.Alloc(InValue));
}
```

`HandleData.Alloc`（`Script/Interop/Handle/HandleData.cs:41-58`）第一行即 `ObjectToHandleReference.GetValue(InObject, …)`；`ConditionalWeakTable` 不接受 `null` 键 ⇒ **抛 `ArgumentNullException`**，且发生在任何 P/Invoke 之前。实测栈（§2.3 改前）：

```
System.ArgumentNullException: Value cannot be null. (Parameter 'key')
   at Interop.HandleData.Alloc(Object InObject, Boolean bIsWeak) in …\HandleData.cs:line 42
   at Script.UnrealCSharpTest.UUnitTestSubsystem.TestOptionalNullReference()
   at Script.UnrealCSharpTest.UUnitTestSubsystem.UUnitTestSubsystem.Test()
```

**语义三选一（审计原文）**：① 设为空值；② 等同未设置；③ 抛明确异常。裁定 **①（A）「值为 null」**，理由：

| 维度 | A「值为 null」（采纳） | B「等同未设置」 | C「抛明确异常」 |
|---|---|---|---|
| 改动面 | **C# 2 处**（本轮） | C# ＋ **native 2 处**（`Register2Implementation:64-71`／`SetImplementation:146-155` 需把句柄 0 转为 `Reset`） | 新增异常面（G7 禁） |
| 语义可分辨性 | `new TOptional<T>(null)` 与 `new TOptional<T>()` **可区分**（`IsSet` 不同） | 两者**不可区分** ⇒ 构造实参被吞掉 | —— |
| 与既有家法一致性 | 与"带值构造"语义一致；C# 侧 `Get()` 对句柄 0 已返回 `default`（`:57-71`） | 与 `GetHandle(null) == 0` 相近，但抹掉 `IsSet` 信息 | —— |
| 运行期风险 | 零 native 改动；`FDomain::GCHandle_Free(0)` 已有 `IManagedHandleIsValid` 守卫（`FScriptDomainImpl.inl:349`） | 需改 native 且要新增分支 | —— |

**native 侧为何接受句柄 0**（本轮逐点核对，非推断）：

- 对象/类：`FObjectPropertyDescriptor::Set`（`Private/Reflection/Property/ObjectProperty/FObjectPropertyDescriptor.cpp:18-27`）→ `GetObject(0)`（`FObjectRegistry.cpp:66-69` → `GetAddress` 表未命中）返回 `nullptr` → `SetObjectPropertyValue(Dest, nullptr)`；随后 `Get()` 走 `Bind(nullptr)` 得 `InvalidManagedHandle` ⇒ C# 侧 `Handle != 0` 为假 ⇒ `default`（`null`）。
- 字符串/名/文本/结构体：对应 `Set` 在句柄 0 时**整块跳过**（`FNamePropertyDescriptor.cpp`／`FTextPropertyDescriptor.cpp`／`FStructPropertyDescriptor.cpp` 的 `if (const auto SrcValue = …GetString/GetStruct(handle))`），而 `FOptionalHelper::Set`（`FOptionalHelper.cpp:101-108`）**先** `MarkSetAndGetInitializedValuePointerToReplace` ⇒ `IsSet == true`、值为默认构造（空串/`NAME_None`/零值结构体）。**不崩、但不是 null** —— 边界见 §2.4。
