        public static void Unload()
        {
            HandleData.Clear();

            TypeBridge.Clear();

            MethodBridge.Clear();

            if (Context != null)
            {
                try
                {
                    Context.Unload();
                }
                finally

                    Context = null;
                }
            }
        }

| **C-ALC-1** | 当前后端运行时 = **LeanCLR coreclr `42.42.42.42424`**（`Binaries/Win64/shared/Microsoft.NETCore.App/10.0.4/coreclr.dll`，同目录 DAC 与 `dotnet-dump` 不兼容）；**不支持 collectible ALC**，`AssemblyLoadContext.Unload()` 为 **no-op**（源码四段见 [`08-…/278`](278-轮B-242-F-LIFE-015追根二-根因在运行时LeanCLR不支持可回收ALC（2026-11-04）.md) §2） |

| **C-ALC-3** | 任何代码不得依赖"域卸载后程序集/内存被回收"；若将来切换到支持 collectible ALC 的运行时，回收由运行时按需完成；**若要重新引入主动等待**，必须另立项并重做（GT 预算 ＋ 并发）评估 |
