## 1. 施工

### 1.1 任务队列（`Compiler` 模块）

```cpp
// FCSharpCompilerRunnable.h
#include "Containers/Queue.h"
	void EnqueueTask(const TFunction<void()>& InTask);   // 新增重载（与既有两个 EnqueueTask 并存）
	TQueue<TFunction<void()>> TaskQueue;                 // 单消费者（编译器线程）/多生产者

// FCSharpCompilerRunnable.cpp
void FCSharpCompilerRunnable::EnqueueTask(const TFunction<void()>& InTask)
{
	TaskQueue.Enqueue(InTask);

	if (Event != nullptr)
	{
		Event->Trigger();
	}
}

// Run()：空闲分支先取任务、再等事件（醒来后即使事件被上一次 Trigger 消费掉，队列也会被重新检查）
		else
		{
			TFunction<void()> Task;

			if (bIsPending)
			{
				DoWork();
			}
			else if (TaskQueue.Dequeue(Task))
			{
				Task();
			}
			else if (Event != nullptr)
			{
				Event->Wait();
			}
		}
```

- **顺序保证**：`bIsPending`（编译请求）优先于队列任务 ⇒ 新编译永远先于积压的分析跑；分析之间按 FIFO。
- **重入**：任务体不触碰 `bIsCompiling`/`bIsPending`，不参与 `AcquireCompile()` 闸门；任务里只做 `SyncProcess`。
- **停止**：`Stop()` 仍只置 `bIsStopped` + `Trigger()`；长任务不可中断，但其 `SyncProcess` 的谓词是 `IsEngineExitRequested()`（B-179 修），退出期会自行收敛。

### 1.2 三处调用点外移

| `FEditorListener::OnCompile` | 先 `FileExists` 过滤并 `AddUnique`，再 `FCSharpCompiler::Get().EnqueueTask([FileChange]{ for (…) FCodeAnalysis::Analysis(File); })` —— **每次编译只投递一次** |

## 3. 刻意保留同步的两处（为什么）

| 位置 | 原因 |
|---|---|
| `FEditorListener::OnPostEngineInit()`（`FCodeAnalysis::CodeAnalysis()` 紧跟 `FDynamicGenerator::CodeAnalysisGenerator()`） | 后者**立即读取**前者写出的 4 个 JSON（`Dynamic.json` 等）；异步化会让生成器读到上一版 |
| `UnrealCSharpEditor.cpp` 的 `Generator()` 慢任务（`FScopedSlowTask` 内 `CodeAnalysis()` → `CodeAnalysisGenerator()`） | 同上，且整体已有进度对话框，属用户显式长任务 |

> 若要连这两处也外移，必须把"分析 ＋ 生成"**打包成同一个任务**一起投递（两段之间保持先后）；这会牵动 `FDynamicGenerator` 在非 GT 的调用面，留作后续。

## 7. 边界

1. **分析仍会与"另一条生成路径"竞争**：编译器线程上的任务与 `DoWork` 同线程串行，但 `FDynamicGenerator::Generator()` 也可能从 GT（如命令行走 `ImmediatelyCompile` 之外的路）触发；本轮未加跨线程门闩（B-180 §2.3 的 B 方案），只消除了**热路径**（每次保存的逐文件分析）。
2. **未实测"分析期间 GT 保持响应"**：探针只证明了任务在哪个线程跑；"不冻结"是线程归属的直接推论，未做 GT tick 间隔采样。
3. **长任务不可中断**：`Stop()` 不打断正在跑的 `SyncProcess`；退出期靠 `IsEngineExitRequested()` 收敛（B-179 修）。
4. **未跑 Mono/LeanCLR**：本轮为编辑器线程模型改动，与脚本后端无关；5.0 只做编译门禁。
