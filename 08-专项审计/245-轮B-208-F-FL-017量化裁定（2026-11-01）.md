## 1. 它不是"复制"，是**分叉**（本轮把分叉点钉死）

对照 `Engine/Source/Runtime/CoreUObject/Public/UObject/UnrealType.h` 的 `TFieldIterator`（5.6），两者**在接口分支上行为不同**：

```cpp
// 引擎 TFieldIterator::IterateToNext()（5.6）
if (bIncludeInterface)
{
    UClass* CurrentClass = (UClass*)CurrentStruct;
    ++InterfaceIndex;
    if (InterfaceIndex < CurrentClass->Interfaces.Num())
    {
        FImplementedInterface& Interface = CurrentClass->Interfaces[InterfaceIndex];
        CurrentField = Interface.Class ? GetChildFieldsFromStruct<…>(Interface.Class) : nullptr;
        continue;
    }
}
```

```cpp
// 插件 TFieldIteratorExt::IterateToNext()（TFieldIteratorExt.inl:110-121）
if (bIncludeInterface)
{
    UClass* CurrentClass = (UClass*)CurrentStruct;
    TArray<UClass*> InterfaceClasses = GetAllInterfaceClasses(CurrentClass);   // ← 每次重建 + 展开接口父链
    ++InterfaceIndex;
    if (InterfaceIndex < InterfaceClasses.Num())
    {
        UClass* InterfaceClass = InterfaceClasses[InterfaceIndex];
        …
    }
}
```

两处差异：

| 差异 | 引擎 | 插件副本 | 性质 |
|---|---|---|---|
| 接口集合 | `CurrentClass->Interfaces` 按索引直接取 | `GetAllInterfaceClasses()`：遍历每个已实现接口并**沿 `GetSuperClass()` 展开父链**、`Contains` 去重 | **语义扩展**（会迭代到接口的基接口字段）——这大概率是副本存在的理由 |
| 代价 | 无分配、O(1) | 每次调用**新建 `TArray`** ＋ `Contains` O(n²) | **额外成本**，本轮量化对象 |

⇒ 「复制且无版本守卫」的真实风险 = **引擎侧接口分支若再改动，这段分叉不会跟着改、也不会报错**（它编译得过，只是行为静默不同）。

## 4. 边界（如实登记）

1. **只测 `-game`**：`FCSharpBind` 的绑定在启动期完成，`-game` 与编辑器都会走同一段；但编辑器会话下的类数可能更多（内容浏览器/热重载），未实测。
2. **未测"分叉导致的字段集合差异"**：本轮只量化成本，没有验证"接口父链展开"是否真的多迭代出字段（那是语义验证，属另一条口径）。若将来要动这段代码，**先做字段集合 A/B**（引擎版 vs 插件版迭代结果 diff）再改。
3. **探针不改变被测行为**：`Iterations++` 与时间戳读取都是常量级开销；`GetAllInterfaceClasses` 的 `FScope` 只加一次取时＋一次累加。
