## 2. `GetReferenceValue` 的两条分支（静态结论）

```cpp
if constexpr (std::is_lvalue_reference_v<Type> && !std::is_const_v<std::remove_reference_t<Type>>)
{
    if constexpr (TIsPrimitive<Type>::Value)
        std::get<Index>(InArgs) = std::get<Index>(InShadowArgs);            // ① 影子拷贝：无句柄
    else
    {
        std::get<Index>(InArgs) = TPropertyValue<Type, Type>::Get(InManagedHandles[Index]);   // ② 自打包句柄
        FDomain::GCHandle_Free(InManagedHandles[Index]);
    }
}
```
- ① **原语引用**（`ref int32` 等）：`ArgumentToParams` 把**影子变量的地址**当 `void*` 参数传给 C#（`:114`）⇒ C# 直接写内存 ⇒ 回来后拷贝 ⇒ **全程无句柄** ⇒ 不可能受哨兵影响；
- ② **非原语引用**（`ref FString`／`ref UObject` 等）：`InManagedHandles[Index] = IManagedHandleFromObject(TPropertyBuilder<Type*, nullptr>::Get(影子参数))` —— 即"把**调用前**的对象/结构指针打包成句柄"；`Get` 走 `FCSharpEnvironment::Get*`（带守卫）⇒ 无效则 `Default`；`Free` 走 C# `TryGetValue` ⇒ 未命中即无操作。

⇒ **静态结论：`GetReferenceValue` 不存在 B-15 那类"判据通过 ⇒ 进入原语转换 ⇒ 解引用 `nullptr`"的形态**（原语根本不走句柄；非原语的句柄不是桥返回值）。

## 4. 🔴 报告更正：消费点清单（B-14/B-15 写错）

- **B-14 报告 §0/§3.1 与 B-15 报告 §1.1 写的**："`Invoke` 返回值的消费点共 **4 处**（`FManagedFunctionDescriptor`／`TMethodHelper.inl:78`／`FDomain::GetTraceback`／`FClassReflection` 3 处丢弃）"；
- **实际**：**使用方 4 处** = `FManagedFunctionDescriptor::Invoke`、`TMethodHelper::Invoke`、`FDomain::GetTraceback`、**`FScriptDomainImpl::GetClassesWithAttribute`**；**丢弃方 5 处** = `FClassReflection` ×3、`FDomain::Initialize/DeinitializeSynchronizationContext` ×2 ⇒ 原文既**多算**了丢弃方（`FClassReflection`）又**漏算**了 Core 层那处。
- **根因**：B-14 的普查用 `grep` 命中后按"`FManagedFunctionDescriptor`／`FMethodReflection`／`FManagedFunctionDescriptor` 三个探针点"的旧印象手工归类，未逐条核对 Core 层（`FScriptDomainImpl.inl` 命中确实出现在输出里，但归类时被漏掉）。
- **已修**：报告 52 §0/§3.1、报告 53 §1.1 与本报告 §1 统一为上述清单；`05 §16` 记录该更正。

### 4.1 补入清单那处的后果（已核实为**无**）

`GetClassesWithAttribute`（`FScriptDomainImpl.inl:547-587`）：异常 ⇒ `Types = -1` ⇒ 判据通过进入块内，但
- `int32 OutLength{}` 初值 **0**（C# 未写回）⇒ **`for` 循环 0 次** ⇒ 不触碰 `ArrayGet(-1,…)`／`GetNamespace(-1)`；
- 块尾 `Free(Types)` ⇒ C# `FreeImplementation(-1)` ⇒ `Handles.TryGetValue(-1)` **未命中** ⇒ **无操作**。
⇒ 实际后果 = "**静默返回空列表**"（与"未找到任何带该属性的类型"同形）；**无崩溃、无副作用**（仅多一次无效跨边界调用）。
