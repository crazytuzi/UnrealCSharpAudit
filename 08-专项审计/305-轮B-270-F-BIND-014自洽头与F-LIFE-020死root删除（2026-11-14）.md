## 1. 改动清单

### 1.1 `F-BIND-014`：`TIsStaticEnum.inl:3`（P3）

```cpp
#pragma once

#include "UObject/ReflectedTypeAccessors.h"

template <typename T>
struct TIsStaticEnum
{
	template <typename U>
	static std::true_type Test(decltype(StaticEnum<U>())*);
	...
```

**为什么这一行就关掉整条**：

1. `TIsStaticEnum` 的探测表达式 `decltype(StaticEnum<U>())*` 在**解析期**就要 `StaticEnum` 的声明（不需要实例化）。
2. 声明的真实位置 = `UObject/ReflectedTypeAccessors.h`（5.0 `:15/23`、5.6 `:23`；5.8 该头转引 `UObject/CoreReflectedTypeAccessors.h`，`StaticEnum` 在 `:11`）。
3. 改前该头只通过 `TStaticEnum.inl:7` 的 `#include "UObject/Class.h"` **间接**进来，而且**排在 `TIsStaticEnum.inl` 之后、还在 `#if UE_REGULAR_UENUM_STATIC_ENUM`（仅 5.8）门控内** ⇒ 5.0–5.7 或任何先包含 `TIsStaticEnum.inl` 的 TU 里 `StaticEnum` 未声明（MSVC `C2065`，不实例化也报），当前只是被模块共享 PCH 掩盖。
4. 修法是**让用它的头自己包含声明它的头**（IWYU 自洽）：`TIsStaticEnum.inl` 在任何包含顺序下都能独立解析；`TStaticEnum.inl` 原门控块保持不动（`UObjectGlobals.h` 仍为 `FindFirstObjectSafe` 所需）。
5. 选 `UObject/ReflectedTypeAccessors.h` 而非 `UObject/Class.h`：前者是**声明所在头**（更窄），且 5.0–5.8 都存在；`Class.h:71`（5.6）/`:5777`（5.8）本身也包含它，所以不会产生"两个头二选一"的分叉。

### 1.2 `F-LIFE-020`：`FRegisterInputComponentHelper.cpp:19-21`（P3，纯删除）

```cpp
			DynamicBindingObject = NewObject<UDynamicBlueprintBinding>(GetTransientPackage(), BindingClass);

			ThisClass->DynamicBindingObjects.Add(DynamicBindingObject);
		}
```

删掉的 6 行：

```cpp
			if (ThisClass->HasAnyInternalFlags(EInternalObjectFlags::RootSet) ||
				GUObjectArray.IsDisregardForGC(ThisClass))
			{
				DynamicBindingObject->AddToRoot();
			}
```

**为什么是死代码 + 冗余（B-267 的双重论证在本轮复核后仍成立）**：

1. `ThisClass` 来自 `GetObject<UBlueprintGeneratedClass>(InThisClass)`（`:9`）⇒ **恒为 BPGC**；
2. BPGC 晚于引擎 `CloseDisregardForGC()` 创建 ⇒ **不可能**在 disregard-for-GC 集合；插件自己的动态类也只 root `UBlueprint`、不 root 类（`FDynamicClassGenerator.cpp:466`）⇒ 也不在 root set ⇒ 守卫**不可达**；
3. `DynamicBindingObjects` 本身就是 `UPROPERTY()`（5.6 `Engine/Classes/Engine/BlueprintGeneratedClass.h:463-464`）⇒ 对象已被 GC 保活，即便守卫成立也是**冗余保活**；
4. 删掉后 **`BindFunction` 的必要 root（`:57-60`）原样保留** —— 那一处对"原生类"是承重的（disregard 类的 `FuncMap` 不被 GC 遍历），且已有解根点（`FRegisterClass.cpp:24-27`），本轮**不动**。
