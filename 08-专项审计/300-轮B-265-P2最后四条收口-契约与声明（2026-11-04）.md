## 1. `F-GEN2-006` → 契约（C 案）

**依据**：B-252 语料实测（405 委托 / 207 skip / **真碰撞 0**）＋ B-262 A 案实测（16 231 代理 **delta 0**）。

| 条款 | 内容 |
|---|---|
| **C-DELEGATE-1** | 命名规则：单播委托命空间**总是**含类名（`outer` 为 `UClass` 时）；多播委托**原生**含类名、**非原生**（BP 类）只到模块级；顶层委托（`outer` = `UPackage`）为模块级 —— 后两者是"同名碰撞"的唯一来源 |
| **C-DELEGATE-2** | 碰撞条件（唯一可构造路径）：**同一模块内两个 BP 类**声明同名 `BlueprintAssignable` 多播委托且签名不同 ⇒ 第二个被静默丢弃。模块顶层同名委托在 C++ 层不可能（重定义） |
| **C-DELEGATE-3** | 规避与检测：用户侧避免"同模块同名 BP 多播委托"；需要核查时按 [`08-…/287`](287-设计页-委托去重键与同名碰撞（F-GEN2-006）（2026-11-04）.md) §5 的探针配方（`[b252]` 日志 + 全量生成）复测 |
| **增长政策** | A 案（命名空间并入类名）是**破坏性改名**，补丁与实测见 [`08-…/297`](297-实施单-F-GEN2-006-A案-多播委托命名空间含类名（2026-11-04）.md)；**留待下一个主版本**与公告一起发，不在 P2 战役内执行 |

## 2. `F-BIND-010` → 契约（C 案）

**依据**：B-249（两个宽度来源）＋ B-261（对齐条件与生成代码实证）。

| 条款 | 内容 |
|---|---|
| **C-ENUM-1** | 跨托管边界的 UENUM **必须写固定底层类型**（`: uint8` / `: int32` …），且与 UHT `UnderlyingType` 一致。UE 自身枚举全部满足（例：`ESlateVisibility : uint8`） |
| **C-ENUM-2** | **未用 `BINDING_ENUM` 注册、且 UHT 宽度 > 1** 的枚举**不得跨边界**（返回值路径 C++ 恒读 1 字节 ⇒ 截断；参数路径 C# 按代理宽度写、C++ 按 `sizeof` 读 ⇒ 仅当声明未写固定类型时分叉） |
| **C-ENUM-3** | 若确需支持：按 [`08-…/296`](296-实施单-F-BIND-010三案落点与判据（2026-11-04）.md) 的 **A-min**（生成期 `TEnumWidth` trait，4 子模块分支）/ **A-full** / **B**（统一 `int64`，协议不兼容）执行；**三者都需要"宽枚举"语料**，本轮未构造 |
| **兜底** | 现有工程内唯一实例 `ETestEnum`（`TestInterface.h:24`，未写固定类型、UHT 宽度 byte）在**返回值方向**恰好正确（C++ 读 1 字节 = 装箱宽度）；参数方向未实测（无宽枚举语料） |

## 4. `F-CS4-010` → 契约归档

**依据**：B-67（接口面关闭）＋ B-255（T1–T4 回 HEAD 复核均未触发）。

| 条款 | 内容 |
|---|---|
| **C-OVERRIDE-1** | `IsOverride` 是**类级**「是否按 C# 动态类绑定」的闸门（唯一消费方 `FCSharpBind::CanBind`），**接口必须返回 0**；接口识别走精确特性类型（`GetUInterfaceAttributeClass`）＋ 引擎 `CLASS_Interface` 标志，**不得**改由 `IsOverride` 驱动 |
| **C-OVERRIDE-2** | `[KismetHideOverrides]` 必须与 `[UClass]` 连用；单独使用会让 C# 侧（派生匹配）与 C++ 侧（精确匹配）判定分叉 |
| **触发（原样保留）** | T1：出现"只写 `[KismetHideOverrides]` 不写 `[UClass]`"的用户实证；T2：出现"把接口当 C# 动态类型绑定"的新需求；T3：接口绑定路径改为 `IsOverride` 驱动；T4：`KismetHideOverridesAttribute` 继承关系被牵动 |
| **T1 时的判据要点** | 须同时纳入 `CanBind` 的 `NotOverrideTypes` 早退（B-67 之后新增，`:455-458`） |
