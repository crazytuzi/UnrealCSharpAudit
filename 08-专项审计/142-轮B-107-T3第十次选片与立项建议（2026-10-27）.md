### 2.6 `F-REFL-003`（2.54 · P2）—— 🟢 **立项 ③：给 `Field2Class` 加惰性清扫**

**HEAD 事实**（`Source/UnrealCSharpCore/Private/Reflection/FReflectionRegistry.cpp`）

```cpp
878:     Field2Class.Empty();                       // 唯一收缩点（Deinitialize 内）
890:     if (const auto FoundClass = Field2Class.Find(InField))   // GetClass(UField*)
927:     Field2Class.Add(InField, FoundClass);                    // 只增不减
```
`grep` 实测：`Field2Class` 的 `.Remove(` = **0**、`.Reset(` = **0**。

**判定**：成立。键是 `TWeakObjectPtr<UField>`（失效后不会误命中，无悬垂），但**条目不会随键失效而移除**；编辑器反复热重载时 `UClass` 反复创建/丢弃 ⇒ map 在两次 `Deinitialize()` 之间**单调增长**（内存 ＋ 哈希冲突 ⇒ `Find` 变慢）。

**出口**：在 `GetClass(UField*)` 的 `Add`（`:927`）前做**惰性清扫**（`CreateIterator()` ＋ `!It.Key().IsValid()` → `RemoveCurrent()`），按 `Field2Class.Num()` 阈值触发（例如距上次清扫翻倍）。≈8 行、0 新 API、0 日志。

**判据**：
1. 静态：`Field2Class` 的 `.Remove(` / `RemoveCurrent(` 计数 **0 → 1**；
2. 运行期（临时探针）：连续 `GetClass` 一批**之后会失效**的 `UField`，失效后再触发清扫 ⇒ `Field2Class.Num()` 不随失效键增长（改前单调增长 / 改后回到存活数）。

**风险**：低（只删无效键；有效键与序列号不受影响）。
