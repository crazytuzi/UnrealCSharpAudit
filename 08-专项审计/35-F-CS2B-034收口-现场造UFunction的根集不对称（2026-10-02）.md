## 1. 前提回核（逐行落代码）

**enhanced 侧**（`FRegisterEnhancedInputComponent.cpp`，改前）：

```cpp
:76   if (const auto FoundFunction = InClass->FindFunctionByName(*InFunctionName))
:77   {
:78       FoundFunction->RemoveFromRoot();     // ← 命中分支：清陈旧 root 标志
:79
:80       return;
:81   }
…
:99   Function->AddToRoot();                    // ← 创建分支：无条件把新 UFunction 钉进根集（本轮删除）
```

**legacy 侧**（`FRegisterInputComponent.cpp`，改前）：

```cpp
:582  if (const auto FoundFunction = InClass->FindFunctionByName(*InFunctionName))
:583  {
:584      FoundFunction->RemoveFromRoot();     // ← 同上（同一轮 `F-CS2B-018` 收口补的配对）
:585
:586      return;
:587  }
…
:605  Function->AddToRoot();                    // ← 本轮删除
```

**登记的问题**：同一个函数名**只创建一次、之后不再以同名 Bind** 的路径上，`AddToRoot()` 执行过、而命中分支的 `RemoveFromRoot()` **永不执行** ⇒ 该 UFunction **永久留在根集**（`GUObjectArray` 的根集不会被 GC，长会话里属于"只增不减"）。

**为什么删它是安全的（E8 原文回核）**：`UClass::AddReferencedObjects` 遍历 `FuncMap` 并把值加入 GC 稳定引用（引擎 `Runtime/CoreUObject/Private/UObject/Class.cpp:4823-4826`）⇒ 只要 UClass 活着，其 `FuncMap` 里的 UFunction 就活着。插件的 `AddFunctionToFunctionMap(Function, …)`（改后 `:93` / `:599`，本轮未动）已经把它放进 `FuncMap`。
