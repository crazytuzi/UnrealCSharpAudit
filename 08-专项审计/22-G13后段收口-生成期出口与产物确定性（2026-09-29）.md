## 5. 复用价值（给下一轮）

1. **"根"判据在本仓不成立**：`GetGenerationPath()` 按"路径首段是否工程模块"分流，而 binding 族（`FBindingClassGenerator`/`FBindingEnumGenerator`）**不查** `IsSkip`/`IsSupported` ⇒ 任何"本趟没往该根写过 ⇒ 不清该根"的判据保护面为 0（实测 2 468 个 UE 根产物）。清理判据只能锚在**配置**（skip）或**来源**（文件头）上。
2. **破坏性规则可以用"替身根"安全取证**：把真根 rename 成 `*.g13b-real`、放 2 文件替身，即可在同一装置上做"改前会删什么 / 改后还会不会删"的 A/B，**不必先备份 50 MB / 16 155 个产物**。
3. **产物扫描器的比较器必须与引擎同形**：`FString::operator<` = `Stricmp`（序号、大小写不敏感）且生成器比较的是**命名空间本体**；把整行 `using X;`（含 `;`）参与排序会因 `;`(0x3B) > `.`(0x2E) 把 `Script.UMG` / `Script.UMG.Widget` 判成非有序（本轮 5 个假阳性，宽松口径 13 653→5 的残差全部由此解释）。
4. **"来源判据"的载体 = 生成器头注释**（`GeneratorHeaderComment`，236 B）；比较前必须 CRLF→LF 归一（替身探针以 CRLF 写入仍命中），且带 BOM 的文件会自然落空（= 非生成器文件，正是想要的语义）。
5. **`bIsSkipGenerateEngineModules` 的真实语义 = "跳过引擎类/结构/枚举"**，**不是**"不写 UE 根"（2 468 个 binding 类产物仍会写出）。
6. **生成装置的 C# 发布不可依赖**（两趟实测相反：一趟未落地、一趟落地 —— 见 §3.5 第 4 条）⇒ 任何改生成器的轮次，跑套件前必须手工 `dotnet build Script/Script.sln -c Debug` 发布，并核对 `Content/Script/*.dll` 晚于最新产物。
7. **`Sort` 的最小形态**：`TSet::Sort([](const FString& A, const FString& B) { return A < B; });` 一行即可（`TSet` 无无参 `Sort`，必须给谓词）；本仓已有 `.Sort([](...))` 先例（`SDynamicClassViewer.cpp:26`）与 `Keys.Sort()` 先例（`FGameplayTagGenerator.cpp:162`）。
